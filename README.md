# Stage Click

안드로이드 8.0 이상에서 사용하는 오프라인 메트로놈입니다.

## 설치
`dist/StageClick.apk`를 휴대폰으로 보내서 엽니다. 파일을 연 앱에 대해 ‘알 수 없는 앱 설치’를 허용한 뒤 설치합니다.

## 사용
- 20–300 BPM, 슬라이더, ±1, TAP 템포
- 2/4, 3/4, 4/4, 5/4, 7/4, 6/8, 9/8, 12/8
- 복합박자 BPM은 점4분음표 기준이며 8분음표마다 클릭합니다. 강박을 켜면 세 개 단위로 강조합니다.
- 소리 3종: 우드, 비프, 클릭. 휴대폰 미디어 볼륨으로 조절합니다.
- 새 곡: 이름, BPM, 박자를 저장합니다.
- 현재 설정 저장: 선택한 곡의 BPM과 박자를 갱신합니다.
- 곡을 길게 누르면 편집, 순서 변경, 삭제가 가능합니다.
- 다음 곡: 다음 프리셋으로 전환하고 첫 박부터 시작합니다. 마지막 곡 다음은 첫 곡입니다.
- 프리셋은 앱을 종료해도 기기에 저장됩니다.
- 화면은 켜진 상태를 유지합니다. 다른 앱으로 이동하거나 화면을 잠그면 정지합니다.

## 빌드
Android SDK platform 35와 build-tools 35.0.0 및 JDK가 있으면 `./build-apk.sh`로 생성합니다. `ANDROID_HOME`을 설정하면 해당 SDK를 사용합니다. Gradle 프로젝트도 포함되어 있습니다.

로컬 설치용 키는 최초 빌드 때 `build/local.keystore`에 생성됩니다. 같은 앱을 업데이트하려면 이 키를 보관하세요. 이 APK는 개인 설치용으로 서명되었습니다.

## v1.1 박 분할
‘한 박당 클릭’ 버튼으로 기본 클릭과 2분할을 바꿉니다. 120 BPM에서 2분할 클릭 간격은 0.25초이며 마디 길이는 유지됩니다. 추가 클릭은 낮고 작은 소리로 구별됩니다. 복합박자의 한 박은 점4분음표이며, 기본 3분할에서 2분할로 바뀝니다. 프리셋에도 이 선택을 저장할 수 있습니다. 기존 프리셋은 기본 클릭을 유지합니다.
